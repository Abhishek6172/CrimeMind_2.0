# Reproducibility guide
Every run writes `run_manifest.json` (run ID `P<phase>-<UTC time>-<git short hash>`, environment, dataset hashes, config, status, errors) and `run_all` writes `run_all_manifest.json` (all step commands/status/durations, 50 dataset hashes, config hashes, frozen-Q40 bundle hashes). To reproduce: check out the commit in the manifest, install requirements, run `python -m research.run_all`. Expected variation: wall-clock latencies (Phase 5/7) differ by machine; metric values are deterministic given seeds (bootstrap seeds fixed). `research/phase8/results/<run>/results_index.md` lists every result file with SHA-256. Known non-determinism: Phase 7 latencies and the concurrency check's accepted/rejected split.
