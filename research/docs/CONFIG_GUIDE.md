# Configuration guide
Experiment configs are version-controlled JSON: `phase3/configs/phase3_config.json` (seeds, Q40 window/limit, bootstrap), `phase4/configs/phase4_config.json` (Q40-R/RAEER parameters; `frozen_before_evaluation: true`), `phase5/configs/phase5_config.json` (ablations, perturbations, sensitivity), `phase7/configs/phase7_config.json` (seeds, scales, repetitions). The frozen Q40 bundle in `research/results/baseline/` must not be edited; changing any weight or window creates a new method, not a Q40 result. Config hashes are recorded in every `run_all_manifest.json`.
