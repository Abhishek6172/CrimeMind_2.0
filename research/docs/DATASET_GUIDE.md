# Dataset guide
`research/datasets/seed_<n>/` holds gzip CSV tables (entities, events, event_entities, evidence, evidence_entities, evidence_events, communications, location_observations, relationships, transactions) and `dataset_manifest.json` with per-table and content SHA-256. `research/ground_truth/seed_<n>.json` holds roles and intended lifecycle steps (evaluator-only). Regenerate with `python -m research.generate_datasets`; a workspace rebuild verifies the content hash against the committed manifest and aborts on mismatch. All entities are fictional; coordinates describe a fictional city.
