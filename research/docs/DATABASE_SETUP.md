# Database setup
1. Install PostgreSQL 16. 2. Application DB: from `backend/` run `python ../scripts/init_db.py --db crimemind --reset` then `python -m synth.seed --db crimemind`. 3. Research databases are created automatically by `research.common.workspace.SeedWorkspace` (`init_db.py --db cm_rw_<seed> --reset`, then seeding from the committed generator) and dropped on exit; a cross-process lock serialises creation. Roles: `cm_app` (least privilege) is created by `init_db.py` from environment variables; `CM_ADMIN_URL_BASE` points at the admin connection. Never run research commands against your application database name.
